# NSE/MCX Premium Terminal - Spike Monitor

A real-time options premium monitoring terminal built with Streamlit and DhanHQ API.

## Features

- ⚡ Real-time combined premium monitoring (ATM Call + ATM Put)
- 📊 Spike detection with customizable thresholds
- 📈 Interactive charts with live updates
- 🎨 Terminal-style dark theme with cyan accents
- 🔍 Filter view for spike-only monitoring
- 📱 Responsive 2-panel layout
